## 1. Nature of the app

Acerola is a CBZ/CBR reader that runs entirely locally on the user's device. There's no account creation, login, or collection of registration data.

## 2. Stored data

All data generated by using the app (library, reading progress, settings) is stored exclusively on the device's local storage. No library, progress, or settings data is sent to the developer's own servers or third-party servers for storage — the only exception involves network connectivity metadata when remote sync between devices is enabled (see section 3). Uninstalling the app permanently removes all locally stored data.

## 3. Connectivity and device sync

Acerola syncs library, history, and reading progress directly between the user's own devices (e.g. desktop and Android), without going through an account or a central database. This sync is optional, and how the connection is established depends on the configuration chosen by the user:

- **Local discovery only (default, free)**: devices find each other via mDNS on the same local network (Wi-Fi/LAN). No connectivity data leaves the local network.
- **iroh's public relay**: when devices aren't on the same network, the app can use the [iroh](https://iroh.computer) project's public relay infrastructure to establish the connection (NAT traversal). The relay only forwards end-to-end encrypted QUIC traffic (TLS 1.3) between devices — it has no access to library content, history, or progress, but, as with any network relay, the connected devices' IP addresses pass through this third-party infrastructure during forwarding.
- **User's own relay (self-hosted)**: the user can run their own instance of `acerola-relay` (open source, MPL-2.0) on their own VPS. In this mode, no third-party or Acerola-developer infrastructure is involved in the connection at all — the user is the sole operator of the relay.
- **Acerola-hosted relay (paid tier, optional)**: a paid alternative where the Acerola developer operates the relay infrastructure. As with the other modes, library content, history, and progress stay end-to-end encrypted (TLS 1.3) and aren't accessible to the relay — only connection metadata (device IP addresses, connection timing and traffic volume, needed to route the connection) passes through the developer's infrastructure while remote sync is in use. Subscription payment data is handled by whichever payment provider is used at checkout — that provider's specific policy will be shown on the subscription screen.

In none of the modes above is library content (files, progress, history) ever stored on relay servers — public, user-operated, or developer-operated — the relay only ever acts as a network traffic intermediary, never as storage. Processing connection metadata in this context is based on the controller's legitimate interest in enabling the sync functionality the user requested (Art. 7, IX, LGPD); for the paid tier, the subscription itself is based on the user's consent when signing up (Art. 7, I, LGPD).

## 4. Third-party requests

To fetch metadata and cover art, the app makes GET HTTP requests to the public **MangaDex** and **AniList** APIs. These requests:

- don't include personal user data (name, email, files, etc.);
- only contain the search parameters entered by the user (e.g. a title);
- expose the device's IP address to those services' servers, as happens with any network request.

Data processing in this context is based on the controller's legitimate interest in providing the functionality the user requested (Art. 7, IX, LGPD). The returned data is only used during app execution and isn't stored externally by us.

Third-party privacy policies:

- MangaDex: <https://mangadex.org/compliance/privacy>
- AniList: <https://anilist.co/terms>

## 5. Data sharing

Acerola doesn't share, sell, or transmit data to third parties beyond the requests described in item 4 (MangaDex/AniList) and the connectivity metadata transit described in item 3 (relay), both strictly necessary for their respective features to work.

## 6. Minors

The app doesn't collect personal data from any user, regardless of age, and isn't specifically directed at minors under 18.

## 7. Data subject rights (Art. 18, LGPD)

Since no personal data is stored by us, exercising rights like access, correction, and deletion happens directly through the user, locally, by managing or uninstalling the app, or by disabling remote sync (item 3). Questions about data eventually processed by MangaDex, AniList, iroh's relay infrastructure, or the payment provider should be directed to those services.

## 8. Security

Even though no personal data is collected, the app follows secure development practices to protect the integrity of its operation, including end-to-end encryption (TLS 1.3) across all device sync, regardless of which connectivity mode is chosen.
